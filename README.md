# MPOP-Solutions

Benchmark instances and best solutions of the Multi-Profit Orienteering Problem (MPOP) reported in

> F. Hammami. Dynamic programming for exact time-slot scheduling within heuristic routing: A matheuristic for the
> multi-profit orienteering problem. *European Journal of Operational Research*.

The repository contains the 98 MPOP benchmark instances and, for each of them, the best solution found by the method of
the paper, with its route and the optimal visit time of every visited customer. It includes the 25 new best known
solutions reported in the paper.

## Contents

```
instances/   the 98 MPOP benchmark instances, by subset (T1, T2, T3, S64, S66, Solomon)
solutions/   MPOP_Best_Solutions.csv          one row per instance
             MPOP_Best_Solutions_Visits.csv   one row per visited customer
```

## Instances

The instances were generated by Kim et al. (2020) and are available at
<http://logistics.postech.ac.kr/Benchmark_Problems_for_MPOP.htm>. They are included here, in the folder of their
subset, so that the solutions can be read together with the data. Please cite Kim et al. (2020) when using them.

Each instance is a folder with two files:

- `<name>_MPOPData.csv`: one row per vertex, with its identifier, its coordinates, its type (0: start depot,
  1: end depot, 2: customer) and its profit in each of the three time slots (morning, afternoon, evening);
- `<name>_OptionFile.csv`: the maximum route duration `Time Limit` and the start and end of each time slot.

## Solutions

`MPOP_Best_Solutions.csv`

| Column | Description |
|---|---|
| `Subset` | T1, T2, T3, S64, S66 or Solomon |
| `Instance` | instance name |
| `Profit` | total collected profit |
| `NewBKS` | `yes` if the solution is one of the 25 new best known solutions of the paper |
| `VisitedCustomers` | number of visited customers |
| `Route` | sequence of vertex identifiers, from the start depot to the end depot |
| `VisitTimes` | visit time of each customer of the route, in the order of the route |
| `ReturnTime` | arrival time at the end depot |
| `Tmax` | maximum route duration |

`MPOP_Best_Solutions_Visits.csv` gives the same solutions with one row per visited customer: instance, position in the
route, vertex identifier, visit time, time slot (1, 2 or 3) and collected profit.

## Conventions

- The travel time between two vertices is their Euclidean distance rounded to the first decimal.
- Waiting is allowed before any visit: a visit time is at least the arrival time from the previous vertex.
- The time slots are closed intervals; a visit at the boundary of two slots collects the larger of the two profits.
- The visit times of each route are optimal for its sequence: they were computed by the exact dynamic program of the
  paper, and the profit of every solution was checked against the value reported in the paper.
